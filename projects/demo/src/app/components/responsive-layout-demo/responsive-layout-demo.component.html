Responsive Layout Demo

A dashboard authored for a wide screen keeps its aspect ratio by default, so on a phone it shrinks until nothing is readable. Set layoutMode="flow" and the cells reflow into as many columns as fit and wrap instead.

Controls

Simulated device

Shrinks the frame around the dashboard and declares the rest of the window as reservedSpace, so the dashboard sees the frame as the space it has. Resizing your browser works the same way without any of this.

Layout mode

fixed flow

fixed is the default: the authored 16 × 8 grid is letterboxed into whatever space is available.

Minimum cell width

{{ minCellWidth() }}px

Columns are dropped as soon as they can no longer be this wide. Raise it for fewer, bigger cells; lower it to keep the authored column count down to narrower screens.

Usage

<ngx-dashboard
  [dashboardData]="config"
  layoutMode="flow"
  [flowMinCellWidth]="{{ minCellWidth() }}"
></ngx-dashboard>

Reflow applies to view mode only — edit mode always shows the authored grid, because drag & drop, cell resize and cell selection address explicit grid coordinates. A reflowed dashboard grows downwards, so give its container overflow: auto.
